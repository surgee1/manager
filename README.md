# Spectrum Manager


[Скачать последнюю версию](https://github.com/surgee1/manager/releases/latest)

## Установка

1. Скачай ZIP менеджера из Releases и распакуй всю папку.
2. Запусти `Roblox Account Manager.exe`. Нужны Windows и .NET Framework 4.7.2 или новее.
3. Установи расширение из папки `Browser Extension`: в Opera GX открой `opera://extensions`, включи режим разработчика, выбери «Загрузить распакованное расширение» и эту папку с `manifest.json`.
4. В менеджере открой «Настройки → Расширение», скопируй код и вставь его в окне расширения.
5. Войди в свой аккаунт Roblox на активной вкладке и нажми «Добавить в менеджер». Ник проверяется самим менеджером через Roblox.

## Добавление через user:pass

«Добавить → Добавить user:pass…» принимает строки `username:password` из буфера, текстового файла или поля ввода. Выбери Chromium или основной браузер Windows. Chromium создаёт отдельную сессию; основной браузер требует расширение 0.5.0+ и после импорта восстанавливает прежний вход Roblox. CAPTCHA и двухэтапное подтверждение выполняются вручную на официальном сайте. Аккаунт сохраняется только после проверки его имени через Roblox. Пароли в списке скрыты; их сохранение можно отключить перед импортом.

При выборе нескольких аккаунтов кнопка «Браузер» открывает отдельные окна Chrome/Edge с независимыми сессиями. Системная надпись об автоматическом управлении браузером нормальна. При ошибке менеджер сообщает этап сбоя и сохраняет аккаунты.

Расширение передаёт выбранную сессию локальному менеджеру на `127.0.0.1:7964`. Данные аккаунтов не загружаются в GitHub. Код подключения, пароли и cookie не нужно никому отправлять.

## Сохранение пароля при входе

В менеджере 6.2.13+ и расширении 0.6.0+ можно сохранять пароль вместе с сессией. Сначала обнови менеджер, затем расширение. В расширении включи **Сохранять пароль при входе в Roblox**, открой `https://www.roblox.com/login` и войди по нику Roblox и паролю. После успешного входа аккаунт автоматически добавится в менеджер или обновится по ID; папка, заметки и псевдоним сохранятся. CAPTCHA и двухэтапное подтверждение проходят на сайте вручную. Если менеджер временно недоступен, открой его и нажми «Добавить в менеджер» в той же вкладке в течение 10 минут.

Опция выключена по умолчанию. Расширение читает поля только при отправке официальной формы входа, временно держит данные в памяти сессии расширения и удаляет их после импорта. Менеджер проверяет новую сессию и совпадение ника перед сохранением пароля. Вход по почте, телефону, ключу доступа или QR не даёт сохранённого пароля; используй ник. Уже выполненный вход и одни cookie не позволяют получить пароль: войди заново. Обычное добавление cookie сохраняет уже записанный пароль аккаунта.

**Добавить → Войти в Chromium** также сохраняет пароль при входе по нику, если в настройках менеджера включено сохранение паролей. Запуск Edge подключается через файл DevTools отдельного временного профиля, чтобы не оставаться на `about:blank` при ошибке чтения вывода процесса. Сохранённый пароль помогает повторить вход, но не продлевает срок действия сессии Roblox автоматически.

## Запуск через ярлык и ошибка обновления 299

Папку программы можно хранить вне рабочего стола и скрыть обычным атрибутом Windows. С версии 6.2.6 аккаунты и настройки привязаны к папке EXE, а не к полю «Рабочая папка» ярлыка. Если база раньше сохранялась в другой рабочей папке и рядом с EXE базы ещё нет, создаётся копия базы и недостающих основных настроек; исходные файлы сохраняются.

Если старое обновление падает с сообщением ReadProcessMemory/WriteProcessMemory, первое исправление установи вручную: закрой менеджер и окно ошибки, открой расположение файла через ярлык, возьми `SurgeeUpdater.exe` из нового ZIP менеджера и замени одноимённый файл в старой папке. Затем запусти менеджер и нажми «Обновить». Либо скопируй содержимое папки `Spectrum-Manager` из нового ZIP поверх старой папки программы. Не создавай отдельную пустую папку вместо обновления своей установки: база должна остаться рядом с EXE.

## Функции

- Русский интерфейс, подсказки, папки аккаунтов, избранные игры и поиск плейсов.
- Единая тёмная рамка со скруглёнными углами и компактными кнопками окна: главное окно, настройки и дополнительные действия. Без светлой системной полосы Windows 10.
- Настройка цветов и 14 визуальных профилей, в том числе «Милый во Франксе» (Зеро Ту), «Убийца Акаме» (Акаме), Hunter × Hunter (Курапика), Gangsta. (Николас и Алекс), Re:Zero (Субару), Канэки, Наруто, Годзё, Урума, «Жестокий хэппи энд» и Nyan Cat. Добавлен Death Note (L). В списке профилей используются названия тайтлов латиницей без имён персонажей.
- Открытие сайта в браузере Windows по умолчанию, отдельное расширение для импорта сессии и ника.
- Кнопка «Браузер» открывает выбранный аккаунт через расширение. Аккаунт можно выбрать и прямо в расширении; ID проверяется перед открытием Roblox.
- Кнопка «Импорт» переносит аккаунты из оригинального `AccountData.json`, включая Windows-защиту на том же компьютере, папки, псевдонимы, заметки и дополнительные поля.
- Запуск обычных серверов, Job ID, старых приватных ссылок и приглашений `/share?code=…&type=Server`.
- Кнопка «Обновить» в главном окне: проверка Releases, скачивание и установка без открытия GitHub в браузере.
- Обновление из ZIP через «Настройки → Обновления».
- Автосохранение Place ID и ссылки приватного сервера при вводе, восстановление после перезапуска.
- Поиск аккаунтов по нику, псевдониму, заметкам и папке (`Ctrl+F`). `Ctrl+Shift+A` выделяет только видимые записи.
- Профили запуска: игра, приватная ссылка и папка под одним именем. Выбор профиля заполняет поля; подключение запускается обычной кнопкой.
- Быстрые команды `Ctrl+K`, включая возврат последнего удаления. Перед удалением аккаунтов сохраняется переносимая копия.
- Экономия ресурсов анимации в фоне; активный менеджер и настройки продолжают обновляться плавно.
- С версии 6.2.15 деформация персонажа рассчитывается в фоновом потоке с ограниченной очередью: интерфейс рисует последний готовый кадр и не ждёт расчёт картинки. Основное окно использует короткий интервал таймера Windows; предпросмотр настроек обновляется отдельно, чтобы не перегружать общий поток интерфейса. Прозрачность портрета и рамки полей кешируются вместо повторного расчёта при перерисовке дочерних элементов.
- В 6.2.16 снижена нагрузка при использовании активного окна: движение персонажа и частицы ограничены 30 кадрами/с, а при открытых настройках — 20; предпросмотр настроек и медленные переливы — 10. Деформация рассчитывается на ограниченном по размеру изображении, а готовая сцена копируется только в запрошенную область. Это устраняет лишнюю постоянную отрисовку 6.2.15; элементы управления и текст рисуются в исходном разрешении.

Обновление проверяет SHA-256 файлов, сохраняет личные данные и создаёт копии заменяемых файлов. При ошибке замены выполняется откат. Сборка проверена автоматическими тестами протокола авторизации и установщика; успешный запуск на каждом аккаунте и компьютере не гарантируется. Проверки входа Roblox нужно проходить на официальном сайте.

## Клиенты Legit / Cheat

В **Настройки → Основные** можно выбрать русский или английский интерфейс, отключить подсказки при наведении и автоматические предложения обновлений. Язык применяется без перезапуска. Новая версия проверяется в фоне при запуске; предложение не запускает установку без выбора пользователя.

Несколько клиентов Roblox разрешены по умолчанию. Явно сохранённый выбор пользователя сохраняется; если Roblox уже открыт, для активации режима его нужно закрыть и запустить заново. Из настроек убраны управление FPS, свой файл настроек клиента и дополнительные параметры телепортации, версии и старого запуска. Менеджер больше не записывает настройки FPS в клиент. Дополнительные подключения находятся в разделе «Инструменты Spectrum».

Иконка Spectrum с буквой S встроена в EXE и окна. После обновления менеджер обновляет значки своих ярлыков на рабочем столе, в пользовательском меню «Пуск» и закреплённых ярлыках; пути и параметры запуска сохраняются. Обновлятор называется `SpectrumUpdater.exe`. Совместимое имя в переходном ZIP нужно старым менеджерам; при первом запуске обновлённый менеджер заменяет его новым именем.

Новые визуальные профили: Kuroko's Basketball, Bleach, Baki и No Game No Life. Для Bleach используется предоставленное изображение Ичиго без растяжения пропорций. Все профили поддерживают настройку движения и цвета.

Режим задаётся каждому аккаунту через выпадающий список в колонке **Prefix**: `Legit` — отдельный официальный клиент, `Cheat` — привязанный EXE, «Без префикса» — обычный зарегистрированный запуск Roblox через Windows. Для партии выбранных аккаунтов пути фиксируются перед первым запуском; последующее редактирование префиксов не меняет уже запущенную очередь. Префиксы входят в переносимые резервные копии.

**Настройки → Запуск → Скачать / обновить Legit** получает текущую версию официального канала LIVE и пакеты с `setup.rbxcdn.com`. Проверяются размеры и контрольные суммы пакетов; установка выполняется в новую папку `%LOCALAPPDATA%\Spectrum Manager\Roblox-Legit`. Привязка переключается только после полной распаковки. Отмена или ошибка сохраняет прежнюю установку. Если выбран Legit, но клиент ещё не найден, скачивание предлагается самим окном подключения. Старые установки автоматически не удаляются.

**Определить Cheat** показывает пути уже запущенных клиентов или ждёт новый запуск до двух минут. Открой нужный Roblox через свой инжектор и дождись привязки. Менеджер не закрывает игры, не устанавливает и не запускает инжектор. Путь можно выбрать вручную. После обновления инжектора определи его клиент повторно, если он переехал в другую папку. Две папки сами по себе не отключают инжекторы, настроенные на все процессы Roblox.

## Вход в выбранный аккаунт

С версии 6.2.7 несколько выделенных аккаунтов открываются кнопкой «Браузер» в отдельных окнах Chromium. Для каждого создаётся независимая сессия; перед переходом на главную Roblox проверяется ID аккаунта. Используется установленный Microsoft Edge, Google Chrome или Chromium, с отдельной временной папкой, без изменения обычного профиля браузера. Закрытие одного окна не завершает вход в остальных. Через меню «Браузер → Открыть выбранные в Chromium» можно открыть так и один аккаунт. Для этой функции расширение не нужно. Сессии этих окон временные: при новом запуске менеджер передаёт их заново.

Нужны менеджер 6.2.0+ и расширение Spectrum Manager 0.4.0+. Дважды щёлкни по аккаунту в списке (с версии 6.2.3) или выдели один аккаунт и нажми «Браузер»: расширение переключит вход в основном браузере Windows. Редактировать поля списка можно клавишей F2. Или открой расширение, найди аккаунт и нажми на него. Переключение меняет аккаунт во всех вкладках Roblox текущего профиля браузера. Другие сайты и профили браузера не затрагиваются. В инкогнито переключение отключено.

Менеджер передаёт сессию только подключённому расширению через loopback API. Ссылка из кнопки содержит одноразовый идентификатор на две минуты, а не cookie. Перед переходом на Roblox расширение проверяет ID выбранного пользователя; при ошибке возвращает прежние сессии браузера. Если сессия завершилась или Roblox требует проверку, войди на официальном сайте и повторно добавь аккаунт в менеджер.

## Обновление расширения

В разделе «Обновления» расширения нажми **Обновить расширение**. Открытый менеджер скачает ZIP из `surgee1/manager`, проверит SHA-256 и версию, затем заменит файлы именно установленной распакованной копии. При ошибке записи заменённые файлы откатываются. Расширение перезагрузится; код подключения сохранится. С версии 6.2.14 менеджер учитывает `extensions.opsettings` Opera GX и автоматически находит загруженную копию по ID. Выбор произвольной папки больше не предлагается. Если путь не определён однозначно, обновление останавливается с ошибкой. Расширение 0.6.1+ после перезагрузки проверяет фактически загруженную версию.

Для перехода со старого расширения 0.3.0 сначала замени его файлы версией 0.4.0 (или используй папку `Browser Extension` обновлённого менеджера) и нажми «Перезагрузить расширение». Следующие обновления устанавливаются кнопкой из расширения. В релизе находятся два архива: Spectrum Manager и расширение.

## Импорт из другого менеджера

Нажми **Импорт** в главном окне и выбери `AccountData.json` исходного Roblox Account Manager. Windows-защита читается только при доступных исходных ключах Windows. Для файла с мастер-паролем понадобится пароль исходного менеджера. Переносимая копия `*.surgee-backup.json` тоже поддерживается.

В предпросмотре показаны новые записи и совпадения. По умолчанию сохраняются текущие сессии; опция замены позволяет взять рабочие сессии из импортируемого файла. Совпадения определяются по ID или нику без ID. Папки и пользовательские поля объединяются, разные заметки сохраняются вместе, конфликтующий старый псевдоним остаётся в дополнительном поле. Перед импортом создаётся переносимая копия. Исходный файл не изменяется.

## Копии и восстановление после переустановки Windows

Открой **Настройки → Аккаунты**. Автоматические копии включены по умолчанию и сохраняются в `Backups` рядом с менеджером: после изменения аккаунтов, при закрытии и раз в день при открытом приложении. Хранятся 30 автоматических копий. Ручные копии и копии перед удалением/восстановлением не удаляются автоматически.

Кнопка **Создать / экспортировать копию…** сохраняет файл `*.surgee-backup.json`. В нём находятся сессии, сохранённые пароли, ники, псевдонимы, заметки, дополнительные поля и папки, включая пустые. Это переносимый JSON без пароля и без привязки к ключам Windows. Не отправляй его другим людям и не добавляй в GitHub. Перед форматированием диска скопируй `Backups` на другой диск или флешку; в настройках можно выбрать другую папку.

После переустановки распакуй менеджер и выбери **Восстановить из копии…**. Контрольная сумма проверяется до изменения базы. Аккаунты объединяются по ID, а при отсутствии ID — по нику. Текущие сессии и заполненные данные сохраняются; недостающие добавляются из копии. Повторное восстановление не создаёт дублей. Если исходный файл не удалось расшифровать, он сохраняется отдельно перед восстановлением; автоматическая перезапись непрочитанной базы заблокирована.

Копия сохраняет аккаунты, но не продлевает срок действия сессий Roblox: для завершённой сессии может понадобиться повторный вход через браузер и расширение.

## Сборка и публикация

Visual Studio Build Tools / MSBuild, .NET Framework 4.7.2 targeting pack, NuGet и Node.js:

```powershell
nuget restore 'RBX Alt Manager.sln'
msbuild 'Tests/RegressionTests.csproj' /t:Build /p:Configuration=Debug /p:PostBuildEvent= /p:GenerateResourceUsePreserializedResources=true
& 'build/Tests/SurgeeRegressionTests.exe'
node --test Tests/extension.test.mjs
./scripts/package.ps1
```

Архивы появятся в `build/artifacts`. Скрипт использует только файлы приложения и исходников и не берёт аккаунты или пользовательские настройки из рабочей папки.

Workflow `.github/workflows/release.yml` собирает и публикует релиз при отправке тега `vX.Y.Z`, совпадающего с версией приложения. Для следующего релиза обнови версии в `ManagerUpdates.cs`, `AssemblyInfo.cs`, `Browser Extension/manifest.json` при изменении расширения и скрипте упаковки, затем отправь новый тег. `GH_TOKEN` workflow получает из стандартного `github.token`; личный токен в исходники не добавляется.
