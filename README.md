# Surgee Manager

Личный менеджер аккаунтов Roblox для Windows на основе [Roblox Account Manager](https://github.com/ic3w0lf22/Roblox-Account-Manager) от ic3w0lf22.

[Скачать последнюю версию](https://github.com/surgee1/manager/releases/latest)

## Установка

1. Скачай ZIP менеджера из Releases и распакуй всю папку.
2. Запусти `Roblox Account Manager.exe`. Нужны Windows и .NET Framework 4.7.2 или новее.
3. Установи расширение из папки `Browser Extension`: в Opera GX открой `opera://extensions`, включи режим разработчика, выбери «Загрузить распакованное расширение» и эту папку с `manifest.json`.
4. В менеджере открой «Настройки → Расширение», скопируй код и вставь его в окне расширения.
5. Войди в свой аккаунт Roblox на активной вкладке и нажми «Добавить в менеджер». Ник проверяется самим менеджером через Roblox.

Расширение читает только сессию активного аккаунта по нажатию пользователя и передаёт её менеджеру на `127.0.0.1:7964`. Данные аккаунтов не загружаются в GitHub. Код подключения и cookie не нужно никому отправлять.

## Функции

- Русский интерфейс, подсказки, папки аккаунтов, избранные игры и поиск плейсов.
- Настройка цветов и 14 визуальных профилей; у семи профилей есть иллюстрации персонажей с процедурной анимацией.
- Открытие сайта в браузере Windows по умолчанию, отдельное расширение для импорта сессии и ника.
- Запуск обычных серверов, Job ID, старых приватных ссылок и приглашений `/share?code=…&type=Server`.
- Кнопка «Обновить» в главном окне: проверка Releases, скачивание и установка без открытия GitHub в браузере.
- Обновление из ZIP через «Настройки → Обновления».
- Автосохранение Place ID и ссылки приватного сервера при вводе, восстановление после перезапуска.
- Поиск аккаунтов по нику, псевдониму, заметкам и папке (`Ctrl+F`). `Ctrl+Shift+A` выделяет только видимые записи.
- Профили запуска: игра, приватная ссылка и папка под одним именем. Выбор профиля заполняет поля; подключение запускается обычной кнопкой.
- Быстрые команды `Ctrl+K`, включая возврат последнего удаления. Перед удалением аккаунтов сохраняется переносимая копия.
- Экономия ресурсов анимации в фоне; активный менеджер и настройки продолжают обновляться плавно.
- Шуточный полноэкранный ROFL MODE, который закрывается Esc или Alt+F4.

Обновление проверяет SHA-256 файлов, сохраняет личные данные и создаёт копии заменяемых файлов. При ошибке замены выполняется откат. Сборка проверена автоматическими тестами протокола авторизации и установщика; успешный запуск на каждом аккаунте и компьютере не гарантируется. Проверки входа Roblox нужно проходить на официальном сайте.

Распакованное расширение не может самостоятельно заменять свой код. В его разделе «Обновления» можно проверить версию, скачать ZIP и перезагрузить расширение после замены файлов в установленной папке. Если расширение установлено из папки менеджера, пакет обновления менеджера также обновляет файлы этой папки.

## Копии и восстановление после переустановки Windows

Открой **Настройки → Аккаунты**. Автоматические копии включены по умолчанию и сохраняются в `Backups` рядом с менеджером: после изменения аккаунтов, при закрытии и раз в день при открытом приложении. Хранятся 30 автоматических копий. Ручные копии и копии перед удалением/восстановлением не удаляются автоматически.

Кнопка **Создать / экспортировать копию…** сохраняет файл `*.surgee-backup.json`. В нём находятся сессии, сохранённые пароли, ники, псевдонимы, заметки, дополнительные поля и папки, включая пустые. Это переносимый JSON без пароля и без привязки к ключам Windows. Не отправляй его другим людям и не добавляй в GitHub. Перед форматированием диска скопируй `Backups` на другой диск или флешку; в настройках можно выбрать другую папку.

После переустановки распакуй менеджер и выбери **Восстановить из копии…**. Контрольная сумма проверяется до изменения базы. Аккаунты объединяются по ID, а при отсутствии ID — по нику. Текущие сессии и заполненные данные сохраняются; недостающие добавляются из копии. Повторное восстановление не создаёт дублей. Если исходный файл не удалось расшифровать, он сохраняется отдельно перед восстановлением; автоматическая перезапись непрочитанной базы заблокирована.

Копия сохраняет аккаунты, но не продлевает срок действия сессий Roblox: для завершённой сессии может понадобиться повторный вход через браузер и расширение.

## Сборка и публикация

Visual Studio Build Tools / MSBuild, .NET Framework 4.7.2 targeting pack, NuGet и Node.js:

```powershell
nuget restore 'RBX Alt Manager.sln'
msbuild 'Tests/RegressionTests.csproj' /t:Build /p:Configuration=Debug /p:PostBuildEvent= /p:GenerateResourceUsePreserializedResources=true
& 'build/Tests/SurgeeRegressionTests.exe'
node --test Tests/extension.test.mjs
./scripts/package.ps1
```

Архивы появятся в `build/artifacts`. Скрипт использует только файлы приложения и исходников и не берёт аккаунты или пользовательские настройки из рабочей папки.

Workflow `.github/workflows/release.yml` собирает и публикует релиз при отправке тега `vX.Y.Z`, совпадающего с версией приложения. Для следующего релиза обнови версии в `ManagerUpdates.cs`, `AssemblyInfo.cs`, `Browser Extension/manifest.json` при изменении расширения и скрипте упаковки, затем отправь новый тег. `GH_TOKEN` workflow получает из стандартного `github.token`; личный токен в исходники не добавляется.
