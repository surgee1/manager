Скачать ZIP расширения

Менеджер скачает обновление из surgee1/manager, проверит ZIP и заменит файлы расширения. Затем оно перезагрузится. Если папку не удастся определить, менеджер предложит выбрать её один раз.

Сессии передаются между расширением и менеджером только на этом компьютере по твоему действию. Для переключения нужен менеджер 6.2.0+.
